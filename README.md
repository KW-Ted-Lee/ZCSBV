# ZCSBV 圖解法練習台

馬偕醫護管理專科學校 視光學科｜雙眼視覺課程教學工具

輸入雙眼視覺檢查數據後，程式會逐步繪出 ZCSBV（清晰單一雙眼視區）圖，判讀六種常見雙眼視覺異常（Duane–White 分類），計算 Sheard、Percival 與 NRA/PRA 處方，並可輸出兩頁 A4 PDF 紀錄。

## 功能

- 八步驟繪圖：需求線 → 隱斜位點 → 隱斜位線（AC/A）→ BI 邊界 → BO 邊界 → NRA/PRA → 調節幅度 → ZCSBV
- 6 m 與近距注視距離標記
- 三種尺度：完整（含調節上界）、放大近距、固定尺度
- 判讀內聚不足、內聚過度、開散不足、開散過度、基本型內斜位、基本型外斜位
- 「先自己判斷」作答模式
- 輸出 PDF（含學生姓名、學號、圖、數據、判讀與處置建議）

## 使用方式

直接開啟網址即可使用，不需安裝。輸入的數據只存在使用者自己的瀏覽器中，不會上傳到任何伺服器。

## 修改單位名稱與版權宣告

開啟 `index.html`，在 `<script>` 開頭找到 `CONFIG`：

```js
const CONFIG = {
  unitName: '馬偕醫護管理專科學校 視光學科｜雙眼視覺',

```
